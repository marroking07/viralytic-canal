# Mi canal · Viralytic AI

Tu canal de videos cortos (YouTube Shorts, TikTok, Reels) que se hace solo:
tú dices de qué es tu canal, la IA escribe los guiones, el robot arma los videos con voz, imágenes, subtítulos y tu personaje,
y tú los **descargas o compartes** desde el celular para subirlos.

> Necesitas una **llave de licencia** (te la dan al comprar). Cada llave sirve para **una sola instalación**.

## Instalar (desde el celular o la computadora)

1. Toca este botón y sigue los pasos (crea tu cuenta gratis de Cloudflare y entra con tu cuenta de GitHub cuando te lo pida):

   [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/marroking07/viralytic-canal)

2. Al terminar, abre el enlace de tu app (termina en `.workers.dev`).
3. Pon tu **llave** y crea tu **contraseña**.
4. En la app: **Mi canal** (de qué es tu canal) → **Personaje** → **Robot** (un toque para conectarlo).

Listo: el robot revisa cada 3 horas y hace los videos del día. Tú solo los descargas o compartes.

## Gratis
Todo corre en los planes gratis de Cloudflare y GitHub de tu propia cuenta.
